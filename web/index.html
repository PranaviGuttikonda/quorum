    Raft keeps a group of servers agreeing on one log of commands, even while some of them crash or the network splits. The servers elect a leader, which copies each command to the others, and a command is committed once a majority has it.

    What you see is the real quorum C++ engine running in WebAssembly: five servers, a simulated network and a key-value client. Click a server to crash or restart it, and drag the timeline to go back to any moment.
